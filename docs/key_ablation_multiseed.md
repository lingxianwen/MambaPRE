# 关键消融五种子复验

## 受控设置

随机种子为 1337、2027、3407、4701、9001。三种变体使用相同架构、数据划分、优化器、训练轮数和早停规则：

- **完整引导模型**：门控引导、角色辅助损失和类型辅助损失全部启用；
- **无引导门控**：保留角色/类型辅助任务，但不对空间门施加结构/载荷监督；
- **无语义辅助损失**：保留门控引导，但将角色和类型辅助损失权重设为 0。

## 解释边界

在粗粒度长包络上，两项机制的置信区间均不跨越 0，支持“结构头部与不透明载荷分流”的设计。在严格 FINS 全字段上，两项收益均未复现，区间跨越 0，且点估计反而有利于消融模型。因此，现有引导机制只能被表述为对粗粒度结构/载荷分段有效，不能表述为对任意载荷内部字段恢复普遍有效。

机器可读汇总位于 `results/key_ablation_multiseed/aggregate.json`，各种子原始输出保留在同一结果目录中。
