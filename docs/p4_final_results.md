# P4 长字段训练增强：最终结果与去留决定

## 执行完整性

- 普通训练集与长字段增强集对三种架构完全一致；每个 batch 固定 26 条普通消息和 6 条长消息，实际长消息占比 18.75%。
- 初筛使用种子 1337、2027，比较 Role-guided Mamba、Boundary-multiscale Mamba 和参数匹配 Transformer。
- Boundary-multiscale 因长包络平均 F1 比 Role-guided 低 0.0323，且种子间方向不一致，停在两种子，不接触封闭测试。
- Role-guided Mamba 与 Transformer 补齐 3407、4701、9001，共五个配对种子。
- 封闭测试在训练与诊断完成后才建立；首次评测前冻结 10 个 checkpoint、验证集选择的阈值、训练配置哈希、封闭数据哈希。
- 聚合结果无缺失项，所有置信区间均基于五种子配对差值。

## 五种子开发诊断

| 数据与指标 | Role-guided Mamba | 匹配 Transformer | 配对差 Mamba - Transformer（95% CI） |
|---|---:|---:|---:|
| 短报文 Boundary F1 | 0.99954 | 0.99930 | +0.00024 [-0.00070, +0.00118] |
| 短报文 Exact-field F1 | 0.99908 | 0.99856 | +0.00052 [-0.00107, +0.00210] |
| 长包络 Boundary F1 | 0.63969 | 0.32288 | **+0.31681 [ +0.21608, +0.41754 ]** |
| 长包络 Exact-field F1 | 0.57160 | 0.29906 | **+0.27254 [ +0.17955, +0.36553 ]** |
| 已查看 FINS Boundary F1 | 0.98939 | 0.98875 | +0.00065 [-0.00173, +0.00303] |

上述结果支持两个有限结论：短报文精度相当；在既有的同域/包络型长消息诊断上，Role-guided Mamba 显著优于匹配 Transformer。已查看 FINS 与长字段训练数据重合，不能用于任何泛化结论。

## 新封闭 OPC UA pilot

封闭集包含 5 条消息、3 个独立 PCAP、5 个会话，长度为 612–620 字节。所有消息具有连续全字段覆盖，与普通训练、验证和受控增强数据无精确字节重合；OPC UA 协议也未出现在训练中。其定位是严格的协议 OOD pilot，而不是同协议未知捕获测试。

| 指标 | Role-guided Mamba | 匹配 Transformer | 配对差 Mamba - Transformer（95% CI） |
|---|---:|---:|---:|
| Precision | 0.41513 | 0.45081 | -0.03569 [-0.27135, +0.19998] |
| Recall | 0.06369 | 0.05860 | +0.00510 [-0.02786, +0.03805] |
| Boundary F1 | 0.10898 | 0.10276 | +0.00622 [-0.04494, +0.05738] |
| Exact-field F1 | 0.02145 | 0.01241 | +0.00903 [-0.01566, +0.03372] |
| Message perfection | 0 | 0 | 0 |

封闭结果不支持“Mamba 在未见协议的长全字段消息上具有显著准确率优势”。两种模型的主要失败都是 recall 极低，Mamba 的小幅均值优势不显著。由于测试已解封，禁止根据这些结果修改阈值、损失或当前 P4 模型并继续在同一集合上声称封闭泛化。

## 去留决定

P4 作为训练增强实验保留，但主张必须收窄：

1. 保留“短报文精度相当”和“既有长包络上 Mamba 显著优于匹配 Transformer”；
2. 保留线性复杂度、吞吐和显存优势作为论文的稳定主证据；
3. 不使用已查看 FINS 支持泛化，不声称 OPC UA OOD 精度优势；
4. 将 OPC UA 封闭 pilot 作为负面泛化结果或局限性报告；
5. 若继续做新的模型轮次，当前 OPC UA 集必须降级为开发集，并另建从未查看的新封闭测试，不能复用本次结果做模型选择。

机器可读证据：`results/p4_final/aggregate_diagnostic.json`、`results/p4/freeze_manifest.json`、`results/p4_sealed/aggregate.json` 和 `data/processed/p4_sealed/manifest.json`。
