# 批次不变位置特征修订

## 问题

旧版融合门将绝对位置归一化为

\[
p_i^a=\frac{\log(1+i)}{\log(1+L_b)},
\]

其中 `L_b` 是当前 batch 的 padding 长度。因此，同一报文与不同长度报文共同组 batch 时，门控输入会发生变化。

## 修订

新版实现使用模型固定窗口 `L_max`：

\[
p_i^r=\frac{i}{\max(L-1,1)},\qquad
p_i^a=\frac{\log(1+i)}{\log(1+L_{\max})},
\]

其中主配置取 `L_max=4096`。相对位置仍描述报文内部位置，绝对位置使用统一尺度；两者都不依赖同 batch 其他报文的长度。

实现位置：`mambapre/model.py` 的 `SpatialFusion`。`tests/test_model.py` 增加了批次组成不变性测试，服务器测试结果为 8 项全部通过。

## 旧检查点敏感性复验

固定五个种子分别用旧检查点和新推理公式重新评估。五个测试集的平均 boundary F1 变化均小于 0.0005；最大单种子绝对变化为 0.00115。ID novel 与 strict FINS 的五个种子结果完全不变。

详细数据见 `results/batch_invariant_revision/pretrained_reval_summary.json`。该复验只说明旧检查点对公式变化不敏感，最终论文结果仍应来自使用新公式完整重训的检查点。

## 完整重训结果与论文决策

使用新公式完整重训五个 guided Mamba-PRE 种子，并对 learned-fusion unguided 对照做相同的五种子重训。最终聚合见 `results/batch_invariant_revision/final_aggregate.json`。

- ID novel：Mamba-PRE 为 0.9995，matched Transformer 为 0.9996，差异不显著；
- source-held-out：0.8907 对 0.9025，Mamba-PRE 显著较低；
- external full：0.7404 对 0.7051，配对置信区间跨零；
- long envelope：0.6612 对 0.4018，配对增益为 0.2595，95% CI 为 [0.1894, 0.3296]；
- strict FINS：0.1271 对 0.3262，继续暴露密集全字段泛化限制。

Guided 与 unguided learned fusion 的 long-envelope F1 分别为 0.6612 和 0.6529；guided-minus-unguided 为 0.0083，95% CI 为 [-0.0801, 0.0967]。因此，论文不再声称 role guidance 提升准确率，只保留其改变门控行为的诊断性结论。

在 long-envelope 上，guided gate 的四层 structural-minus-payload separation 为 0.582、0.818、0.865、0.819，而 unguided 为 0.019、0.015、0.080、0.137；四层配对差异的 95% CI 均不跨零。这支持“监督改变门控行为”，但不支持“监督提升分割准确率”。
