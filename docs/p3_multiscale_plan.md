# P3：边界感知多尺度门控实验计划

> **状态：已完成并停止。** 五种子结果未达到预设保留条件，P3 仅作为失败消融。完整结果与决策见 `docs/p3_multiscale_results.md`。

## 假设

严格 FINS 的主要失败是边界召回率过低。原角色门控把完整型号字段视为载荷并偏向全局流，忽略了重复字段首尾附近的局部证据。P3 检验：将门控监督改为边界邻域目标，是否能在不增加模型参数的情况下提高严格长报文召回率和 F1。

## 变体

1. **Role-guided**：原始结构/载荷二元目标；
2. **Boundary-multiscale**：在每个字段切点半径 0、1、3 内分别赋予 1.00、0.67、0.33 的局部流软目标；
3. **Hybrid-multiscale**：保留非载荷结构字节的局部目标，同时为载荷内部边界加入上述多尺度软目标。

三种变体使用完全相同的 2,191,502 参数模型、核心语料训练/验证划分、30 轮上限、早停、优化器、学习率、损失权重和五个随机种子。严格 FINS 阈值只在捕获隔离校准集上选择，然后冻结用于测试。

## 决策规则

- 主要指标：严格 FINS 边界召回率和边界 F1；
- 支持修复：相对原角色门控的五种子配对 F1 95% CI 下界大于 0；
- 保留旧主张：长包络和短报文 F1 不出现实质性下降；
- 若只有单种子改善或置信区间跨 0，则只能作为探索性结果；
- 公开真实子集仅一条消息，继续单独汇报且不用于普遍性主张。
